# UX Flow

The concept introduces a date-based clearing flow within the existing chat-clearing experience.

## Flow Overview

```text
Existing Chat
     ↓
Overflow Menu
     ↓
More
     ↓
Clear Chat
     ↓
Choose Clear Method
     ↓
Select Date / Date Range
     ↓
Review Selection
     ↓
Confirm
     ↓
Undo Snackbar
     ↓
Cleared History Marker
